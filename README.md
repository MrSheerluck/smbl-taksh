# taksh

A Rust AI agent toolkit and coding agent, inspired by [Pi](https://github.com/earendil-works/pi).


## Planned crates

| Crate | Responsibility |
|---|---|
| `taksh-ai` | Multi-provider LLM API, streaming, auth, model catalog |
| `taksh-agent` | Agent loop, event stream, tool dispatch, cancellation |
| `taksh-tools` | Built-in tools and tool exposure model |
| `taksh-session` | Tree-structured JSONL sessions, compaction |
| `taksh-cli` | Config, resources, print/JSON/RPC modes |
| `taksh-tui` | Terminal UI |
| `taksh-ext` | Extensions, MCP, packages |
